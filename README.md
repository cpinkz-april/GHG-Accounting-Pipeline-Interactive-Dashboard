# GHG Accounting Pipeline & Interactive Dashboard
Simulate a greenhouse gas (GHG) emissions calculation system (Scope 1 or Scope 2) for an organization, factory, or building, and develop a reporting dashboard.

Descriptions:
1. Ingest activity data (electricity usage in kWh).
2. Multiply activity data by standard carbon footprint Emission Factors (EF).
3. Convert all output values into tCO2e.
4. Build a dashboard to display emission proportions, peak emission months, and future projections.
